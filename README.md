# MyCV

这是一个适合部署到 GitHub Pages 的单页在线简历模板。

## 文件说明

- `index.html`: 页面结构与简历内容
- `styles.css`: 页面样式
- `script.js`: 滚动出现动画

## 如何发布到 GitHub Pages

1. 在 GitHub 新建一个仓库，比如 `mycv` 或 `username.github.io`
2. 把当前目录中的文件上传到仓库根目录
3. 进入 GitHub 仓库设置页 `Settings > Pages`
4. 在 `Build and deployment` 中选择：
   - `Source`: `Deploy from a branch`
   - `Branch`: `main`，目录选 `/ (root)`
5. 保存后等待几分钟，GitHub 会生成公开访问链接

如果仓库名是 `username.github.io`，网址通常会是：

`https://username.github.io/`

如果仓库名是普通项目名，比如 `mycv`，网址通常会是：

`https://username.github.io/mycv/`
